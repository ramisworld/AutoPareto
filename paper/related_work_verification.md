# Original-source verification and novelty boundary

The local `audit/literature/` directory contains retrieved original PDFs, metadata pages, and extracted text. `audit/reference_metadata.json` records author order, title, source URL and page hash. Metadata-only publication timestamps must not be confused with conference years: NeurIPS 2025 proceedings pages currently expose an April 2026 publication date; references use conference year 2025.

| Work | Original source and reading | What it establishes | Difference / consequence for this paper |
| --- | --- | --- | --- |
| autoresearch | [Official repository](https://github.com/karpathy/autoresearch), archived README | An agent edits training code in a five-minute loop; human instructions live in program.md. | Direct precursor, not a novel loop introduced here. |
| Ferreira et al. | [arXiv 2603.24647v5](https://arxiv.org/abs/2603.24647v5), revised 17 April 2026; abstract, experimental setup, Centaur discussion | Classical HPO can outperform LLMs in fixed spaces; code editing narrows the gap; Centaur couples CMA-ES state with an LLM. | Do not claim universal agent superiority. Centaur is not a locally measured baseline. |
| Primer | [NeurIPS 2021 paper](https://papers.nips.cc/paper_files/paper/2021/file/2f3c6a4cd8af177f6456e7e51a916ff3-Paper.pdf), search objective section | Explicitly describes a fixed-budget implicit efficiency objective and the trade-off between step cost and sample efficiency. Its useful modifications can increase step time. | This is strong prior art against claiming the efficiency/exposure incentive itself is new. The proposed distinction is measuring the behavior of a language-model researcher under different contracts, not discovering that fixed budgets matter. |
| MOTE-NAS | [NeurIPS 2024 paper](https://proceedings.neurips.cc/paper_files/paper/2024/file/b6e118c759c16f2424997bbb6a1ffd61-Paper-Conference.pdf), introduction and method | Training-based estimates combine landscape and convergence-speed information for efficient architecture ranking. | Its multi-objective estimate is not the same as our three deployment/quality objectives. Cite without conflating them. |
| einspace | [NeurIPS 2024 paper](https://papers.nips.cc/paper_files/paper/2024/file/0382cb76309820f71c6eacd47b36ce71-Paper-Conference.pdf), search-space construction | A parameterized probabilistic context-free grammar expresses diverse neural operations and architectures. | Open architecture expressivity is prior work. Our comparison must disclose different search spaces. |
| AutoDiscovery | [NeurIPS 2025 paper](https://papers.neurips.cc/paper_files/paper/2025/file/23b127521af7ca7a42f5cdb7507be4f2-Paper-Conference.pdf), hypothesis formalization and search | Bayesian-surprise-guided hypothesis discovery using tree search and empirical verification. | Related autonomous-science policy design; not a test of fixed training time versus counted tokens. |
| MLE-STAR | [NeurIPS 2025 paper](https://papers.nips.cc/paper_files/paper/2025/file/a9619dd0f0d54a5cf7734add1dc38cd1-Paper-Conference.pdf), refinement and ablation | Web retrieval initializes solutions; ablation-guided component refinement and ensembling improve MLE. | Supports agent-system context, not AutoPareto's proposed budget mechanism. |
| AI-Researcher | [Original preprint](https://arxiv.org/abs/2505.18705), pipeline and Scientist-Bench sections | Coordinates literature, hypothesis, implementation and manuscript stages and evaluates research outputs. | End-to-end agent research is prior work; we must specify narrower agent/human boundaries. |
| MLE-Dojo | [Original preprint](https://arxiv.org/abs/2505.07782), environment framework | Interactive, executable MLE tasks support iterative evaluation and training of agents. | Relevant to harness evaluation and reproducibility, not a direct budget-contract control. |
| MONAQ | [Findings EMNLP 2025](https://aclanthology.org/2025.findings-emnlp.918/), Sections 3.1--3.3 | Natural-language constraints and multimodal time-series queries guide specialized LLM design/search/code/evaluation agents toward performance and complexity targets. | Direct prior art against a first multi-objective architecture agent. Its user constraints already form part of the task; our proposed distinction is an explicit behavioral intervention study. |
| Hyperband | [JMLR paper](https://jmlr.org/papers/v18/16-558.html), Section 3.1 | Successive halving allocates more resources to promising configurations over alternative allocation brackets. | Resource-allocation context; not evidence for a cognitive or behavioral agent effect. |
| BOHB | [PMLR paper](https://proceedings.mlr.press/v80/falkner18a.html), Sections 3--4 | Combines model-based configuration selection with Hyperband's multi-budget evaluation. | Budget-aware optimization is established; no broad budget-novelty claim is warranted. |

No exhaustive novelty search or “first” claim is made. Original PDFs were inspected for method-level context; the paper does not reproduce external numerical results. The Primer PDF title includes “Primer:” although the proceedings metadata omits it; use the PDF title in the bibliography. Human author verification of every reference remains pending.
